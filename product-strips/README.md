# Product strip card style

`product-strip.css` restyles Quickly product strips to the mockup: 118px cards, 14px corners, 1px #EEF0F2 border, plain bold price, green outlined ADD.
It was tested by injecting it into the live `#product_strip_quickcommerce_134` the same way Zepio prefixes custom CSS (see `preview-before.png` / `preview-after.png`).
Paste it into the Custom CSS of each product strip (Trending, For Bulalo, Essentials, Bestsellers).
